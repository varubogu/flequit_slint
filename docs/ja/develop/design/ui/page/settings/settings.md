# 設定

> 実装の正本: `crates/flequit-ui/ui/views/settings/settings-dialog.slint` と
> `crates/flequit-ui/src/viewmodels/settings/`。

- 設定画面はモーダルウインドウとして表示する。
- 画面左上に「戻る」ボタンを配置する。
- 画面左のサイドメニューに設定カテゴリ、画面右にはすべての設定項目を表示する。
- サイドメニューに検索ボックスを用意し、設定項目を検索できるようにする。
- サイドメニューを選択した時、右側の設定項目をその位置までスクロールする。

設定変更は ViewModel が楽観的に画面へ反映し、単一の保存キューから
`flequit-settings` へ即時保存する。保存に失敗した場合は最後に保存できた値へ戻し、
エラーバナーを表示する。UI クレートは `flequit-settings` に直接依存せず、
`SettingsStore` ポートの実装を `flequit-app` が注入する。

## レイアウト

| ブレークポイント | 表示 |
| --- | --- |
| `Expanded` / `Medium` | 上記のとおり 2 ペインのモーダル |
| `Compact` | カテゴリ一覧 → 項目一覧の 2 階層遷移。戻るボタンで上位へ |

詳細は [レスポンシブレイアウト](../../responsive-layout.md) を参照。

## プラットフォームによる項目の出し分け

対応していない機能の設定項目は表示しない。判定は `Capabilities` global を参照する。

| 設定項目 | 表示条件 |
| --- | --- |
| システムトレイに常駐 | `Capability::SystemTray` |
| グローバルショートカット | `Capability::GlobalHotkey` |
| アプリ内自動アップデート | `Capability::SelfUpdate`（ストア配布版では無効） |
| エクスポート先の指定 | `Capability::ArbitraryFilePath` |
| インストール済みフォントの一覧 | `Capability::FontEnumeration`（無い場合は `default` / `system` のみ） |

詳細は [プラットフォーム抽象化](../../../platform/platform-abstraction.md) を参照。

## 設定項目

- 基本設定
  - 言語（`en` / `ja`。選択は即時反映され、設定ファイルへ保存する）
  - 曜日開始日（コンボボックス、選択肢は「日曜日」「月曜日」、デフォルトは「日曜日」）
  - 期限ボタングループの表示有無（いずれもON/OFF、デフォルトは今日、明日、今週がON、それ以外はOFF）
    - 期限切れ
    - 今日
    - 明日
    - 3日
    - 今週
    - 今月
    - 今期
    - 今年
    - 今年度
  - 期限フィルター・リマインダー候補・繰り返し項目の呼び名
    （「今期」「今Q」「3ヶ月以内」のように呼び方はユーザーごとに異なるため、
    組み込み・追加済みの各項目に名前を付けられる。Enter かフォーカスが外れた時点で保存し、
    空欄にすると既定の表示名に戻る。名前は表示名だけを変え、同一性は単位と値で判定する）
  - 期限ボタングループ追加（単位「分 / 時間 / 日」と値、任意の名前を指定して
    「10分以内」「1時間以内」「5日以内」などの項目を追加できる。
    追加は頻繁に行わないため、フォームは「期限フィルターを追加」ボタンを押すまで折りたたむ）
  - リマインダー候補追加（単位「分 / 時間 / 日」と値、任意の名前を指定する。
    フォームは「リマインダー候補を追加」ボタンを押すまで折りたたむ）
  - 繰り返し設定のカスタム項目追加（単位「日 / 週 / 月 / 年」と間隔、任意の名前を指定して
    「2週間ごと」などを登録し、繰り返しエディタからワンクリックで適用できる。
    フォームは「繰り返し項目を追加」ボタンを押すまで折りたたむ）
- 日時設定
  - IANA タイムゾーン（`system` / `UTC` を含む。テキスト入力で絞り込み、
    候補一覧から選んで確定するコンボボックス）
  - 現在の日時フォーマットとプレビュー
  - プリセットの試行と適用
  - カスタムフォーマットの追加・上書き・削除
- 外観設定
  - テーマ（コンボボックス、選択肢は「デフォルト」「ダーク」「ライト」、デフォルトは「デフォルト」）
    - 将来的に独自のテーマも適用可能にする予定
    - 条件つきテーマも採用予定。期日のものは目立つよう赤文字にするなどの設定を追加予定
  - フォント（絞り込みコンボボックス。「default」「system」に加えて
    インストール済みのフォントファミリを列挙する、デフォルトは「default」）
  - フォントサイズ（数字テキストボックス、デフォルトは「13」）
  - フォントカラー（コンボボックス、選択肢は「デフォルト」「黒」「白」、デフォルトは「デフォルト」）
  - 背景色（コンボボックス、選択肢は「デフォルト」「白」「黒」、デフォルトは「デフォルト」）
- アカウント設定
  - 現在のアカウント種別、表示名、メールアドレス、認証プロバイダーを表示する
  - ver1.0 はローカルアカウントを使用し、クラウドアカウントの追加導線は将来対応として表示する

以下のアカウント固有項目はクラウドアカウント対応時に有効化する。
ローカルアカウントでは表示情報のみとし、編集 UI は出さない。

- 組織アイコン（表示のみで変更不可）
- 組織名（表示のみで変更不可）
- アカウントアイコン（ファイルアップロードボタン）
- アカウント名（テキストボックス）
- メールアドレス（テキストボックス）
- パスワード（パスワード入力テキストボックス）
- サーバーURL（テキストボックス）
- ソーシャルログイン
- タスクテンプレート
- 営業曜日
- 営業時間

## 現在の実装範囲

- 基本設定: 言語、週の開始曜日、組み込み期限フィルターの表示切替と呼び名、カスタム期限フィルター
  （分 / 時間 / 日）の追加・改名・削除、リマインダー候補の追加・改名・削除、
  繰り返し設定のカスタム項目（単位 × 間隔）の追加・改名・削除
- 日時設定: タイムゾーン（絞り込みコンボボックス）、日時フォーマット、プレビュー、
  プリセット、カスタムフォーマットの永続化
- 外観設定: テーマ、フォント、フォントサイズ、フォント色、背景色の選択と永続化。
  いずれも選択が即座に描画へ反映される（フォントは `AppWindow.default-font-family`
  を通して適用する）
  （テーマは `Theme.dark` と std-widgets の `Palette.color-scheme` の両方を切り替える）
- アカウント設定: 現在のアカウント情報の表示
- プラットフォーム項目: `Capabilities` が対応を示す項目のみ表示
- レスポンシブ: `Expanded` / `Medium` は全項目をスクロール表示し、`Compact` はカテゴリ一覧と詳細の二階層遷移

## テーマの適用

- `Theme.mode`（system / light / dark）から `Theme.dark` を導出し、
  すべての色トークンが `Theme.dark` だけを見る
- `AppWindow.init` で Slint が持つ起動時の OS 配色を `Theme.system-dark` へ退避し、
  `flequit-platform` の配色監視で起動後の変更を継続反映する。`Theme.dark` の変化に合わせて
  `Palette.color-scheme` を書き戻し、std-widgets（LineEdit や ComboBox など）も
  同じ配色で描画させる
- フォント色と背景色は `Theme` の色トークンへ反映する。旧設定値の
  `#000000` / `#FFFFFF` は既定色として扱い、テーマ追従を維持する
