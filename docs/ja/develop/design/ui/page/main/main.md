# メイン画面

アプリケーションのメイン画面（サイドメニュー / タスク一覧 / タスク詳細）の仕様。

> 画面幅によるレイアウト切替は [レスポンシブレイアウト](../../responsive-layout.md) を参照。

## データ構造について

- プロジェクト
  - リスト
    - タスク
      - サブタスク

## サイドメニューのデザイン・動作について

- デザインはすべて左寄せとする（折りたたみをするとアイコン＋タイトル→アイコンのみになるような位置とする）
- サイドメニューはすべて<SVGアイコン+名前>の形式で表示する。
  アイコンは `ui/assets/icons/*.svg` に置き、`components/icon.slint` の `Icon` が
  テーマ色で塗り分ける（`@image-url` はコンパイル時解決のため、名前は `IconName` に列挙する）。
- 折りたたみ時にはアイコンのみを表示する。
  - プロジェクトはアイコン未設定が可能。その場合は折りたたみ時にプロジェクト名の先頭2~3文字を表示する。
- クエリで絞り込み中の項目は背景色を変える。サイドバーは独立した選択状態を持たず、
  ハイライトは検索クエリから導出する（[検索](./search.md) の「サイドバーのハイライト」）。

### 折りたたみボタン

アイコンのみ表示、クリックするたびにサイドメニューの折りたたみと展開を切り替える

### 検索テキストボックス

タスク一覧は検索ボックスのクエリだけで決まる。構文・名前の解決・多言語対応・
入力候補は [検索とタスク一覧の絞り込み](./search.md) で定義する。

- 期限（`@今日`）、状態（`@完了`）、プロジェクト（`@仕事`）、リスト（`@仕事.今週やる`）、
  ユーザー（`@山田`）、タグ（`#買い物`）、自由語を AND / OR / NOT / 括弧で組み合わせる
- 見た目は `@山田` と短く、内部では `@user:{UserId}` のように対象を確定させて持つ。
  名前が複数の対象に当たる場合は、検索ボックスの直下に出る一覧から選ぶ
- クエリは端末ごとの設定へ保存し、次回の起動時に復元する

### 期限ボタングループ・状態ボタン

期限ボタン（期限切れ / 今日 / 明日 / 3日 / 今週 / 今月 / 今期 / 今年 / 今年度、およびカスタム期限）と、
状態ボタン（未完了 / 完了）は、対応するキーワードを検索ボックスへ書き込む。
キーワードと期間の定義は [検索](./search.md) の「構文」を参照する。

※期限はいずれも時間単位を無視する（「今日」で1日の12時に表示していた場合、1日の23時59分59秒までのタスクを表示する）。
分・時間のカスタム期限フィルタだけは現在時刻からの相対時間で判定する。

ボタンの件数は、そのボタンだけをクエリにしたときに一覧へ出る行の数とする。

### <プロジェクト名>・プロジェクト内タスクリストボタン

プロジェクトを押すと `@プロジェクト名`、リストを押すと `@プロジェクト名.リスト名` を検索ボックスへ書き込む。
プロジェクトはアコーディオンになっていて、リストの一覧を折りたためる。

### サイドバー項目の操作

期限ボタン・状態ボタン・プロジェクト・リスト・タグブックマークに共通する。

| 操作 | 動作 |
| ---- | ---- |
| クリック | クエリを置き換える（クエリがその項目だけのときはクリアする） |
| Command（macOS）/ Ctrl + クリック | AND で追加する（すでに AND の項にあれば取り除く） |
| Option（macOS）/ Alt + クリック | OR で追加する（すでに OR の項にあれば取り除く） |
| 右クリック（Android は長押し） | コンテキストメニュー（この条件で表示 / AND で追加 / OR で追加 / 除外する / 条件から外す） |

詳細は [検索](./search.md) の「サイドバー操作」を参照する。

### アカウントボタン

ユーザーのアイコンと名前を表示する。
クリックすると下記メニューを表示する。

ver1.0 はローカルアカウントのみを扱うため、設定、アカウント設定、ヘルプを表示する。
アカウント設定は設定モーダルのアカウントカテゴリを直接開き、ヘルプはプロジェクトの
ヘルプページを既定ブラウザで開く。

- クラウドアカウント対応後、ログインしていない場合
  - 設定
  - ヘルプ
  - ログイン
  - ユーザー作成
- クラウドアカウント対応後、ログインしている場合
  - 設定
  - ヘルプ
  - プロフィール
  - ログアウト

## タスク一覧のデザイン・動作について

### 空状態

タスクが表示されない理由に応じて説明と次の操作を切り替える。

| 状態 | 導線 |
| ---- | ---- |
| 検索結果が 0 件 | 検索条件をクリア |
| プロジェクトが 0 件 | プロジェクト作成を開く |
| リストが 0 件 | タスクリスト作成を開く |
| タスクが 0 件 | クイック追加欄へフォーカス |

### クイック追加と追加先

一覧の下部の追加欄でタスクを追加する。一覧はクエリで決まり、見ているリストが一意に決まらないため、
追加欄の左に追加先（`プロジェクト › リスト`）を選ぶボタンを置く。既定の追加先の決まり方は
[検索](./search.md) の「タスクの追加先ピッカー」を参照する。

### 並び替えバー

一覧の上部に「手動 / 期限 / 優先度 / 名前」の 4 ボタンを並べ、選択中は背景色を変える。

| 並び順 | 内容 |
| ------ | ---- |
| 手動   | 保存された表示順（`order_index`）。ドラッグ&ドロップで変更できる唯一の並び |
| 期限   | 期限の早い順。期限なしは末尾 |
| 優先度 | 優先度の高い順 |
| 名前   | タスク名の昇順（大文字小文字を区別しない） |

いずれも安定ソートとし、同値のときは保存順を保つ。
並び順はセッション内でのみ保持する（永続化は将来の view 設定に含める）。

### ドラッグ&ドロップ

タスク行の左端にドラッグハンドルを表示する。ハンドルを掴んで動かしている間、

- 掴んだ行は半透明になる
- タスク一覧の上では、落ちる位置の行の上端に挿入線を表示する（手動並び順のときのみ）
- サイドバーのタスクリストの上では、そのリストを枠線で強調する

ドロップ先による動作は次のとおり。

| ドロップ先 | 動作 |
| ---------- | ---- |
| タスク一覧 | その位置へ並び替える（手動並び順のときのみ） |
| サイドバーのタスクリスト | そのリストの末尾へ移動する |

リスト間移動は同一プロジェクト内に限る。タスクはプロジェクト単位で保存されるため、
プロジェクトをまたぐ移動は別の操作として扱う。移動できないリストは強調しない。

ポインタを使えない場合に備え、ハンドルは increment / decrement のアクセシビリティ
アクションに応答し、1 段ずつの移動ができる。
