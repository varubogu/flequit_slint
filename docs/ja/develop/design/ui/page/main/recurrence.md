# 繰り返しタスクと次の回の生成

繰り返しを持つのは最上位のタスクだけで、サブタスク（親を持つタスク）は自分の繰り返しルールを持たない。
繰り返すタスクを完了にすると、その場で次の回のタスクとすべての深さのサブタスクを作り、
繰り返しルールを次の回へ引き継ぐ。

- 画面全体の構成: [メイン画面](./main.md)
- 実装: `crates/flequit-ui/src/viewmodels/recurrence/`、
  `crates/flequit-ui/src/viewmodels/app.rs`
- 対応するエンティティ: [プロジェクト系エンティティ](../../../data/entity/projects.md) の
  `RecurrenceRule` / `TaskRecurrence`

## 1. 基本方針

1. **繰り返しを持つのは最上位のタスクだけ**。サブタスクは繰り返しの編集 UI を持たず、
   ルールも持たない。繰り返すのは最上位のタスクで、サブタスクはそれに付いて作り直される
2. **次の回は完了にした時点で作る**。未着手・進行中などの間で状態が変わっても何もしない
3. **ルールは複製せず引き継ぐ**。1 つのルールを 2 つのタスクが共有しないため、
   次の回で間隔を変えても完了済みの回には影響しない
4. **期限は相対日時で決める**。完了した回のタスクとサブタスクの間隔をそのまま保つ
5. **完了の取り消しは、次の回が手つかずのときだけ取り下げる**

## 2. 次の回の期限

| 用語 | 決め方 |
| --- | --- |
| アンカー | 完了したタスクの期限 `plan_end_date`。期限が無いときは完了した時刻 |
| 次回期限 | ルールがアンカーの次に示す日時（暦日の判定には表示タイムゾーンを使う） |
| ずれ幅 | 次回期限 − アンカー |

タスクの開始日時・リマインダー、およびサブタスク（どの深さも）の開始日時・期限・リマインダーは、
すべて同じ**ずれ幅**だけ動かす。これによりタスクとサブタスクの間隔が次の回でも保たれる。

例：1 週間繰り返しで、完了した回のサブタスクの期限が 1/3、タスクの期限が 1/5 のとき

| | 完了した回 | 次の回 |
| --- | --- | --- |
| サブタスク | 1/3 | 1/10 |
| タスク | 1/5 | 1/12 |

- 期限を持たないサブタスクは、次の回でも期限を持たない
- 期限を持たないタスク（アンカーが完了時刻）のリマインダーは、タスクのものもサブタスクのものも引き継がない

## 3. サブタスクの作り直し

完了した回のサブタスクは、すべての深さで、次の回のタスクに属する別のサブタスクとして作り直す。
親子の形はそのまま保ち、作り直したサブタスクは作り直した親に属する。親を先に作る。

| 引き継ぐもの | 引き継がないもの |
| --- | --- |
| 名前、ノート、優先度、タグ、担当者、表示順 | 識別子（新しく採番する） |
| 期間指定フラグ `is_range_date` | 状態（未着手に戻す） |
| 開始日時・期限・リマインダー（ずれ幅だけ動かす） | 実績日時 `do_start_date` / `do_end_date` |
| | 繰り返しルール（サブタスクは持たない） |

- 削除済みのサブタスクは、その配下ごと作り直さない
- サブタスクのタグは、タスクのタグと同じく関連付けを別に作る

## 4. ルールの引き継ぎ

- 完了したタスクと繰り返しルールの関連を外し、次の回のタスクに付け替える
- 回数指定（`max_occurrences`）は 1 つ減らして渡す。残りが尽きた場合と、
  終了日（`end_date`）を過ぎた場合は次の回を作らない
- 編集 UI が描かない営業日補正・日付条件は、保存のたびに失われないよう温存する

## 5. 完了の取り消し

完了を取り消したとき、直前に作った次の回が**手つかず**であれば取り下げる
（タスクを削除し、ルールを元のタスクへ戻す）。サブタスクはすべての深さで、タスクの削除と同じ
トランザクションで消える。

手つかずとみなす条件は、次の回が作られたときのまま何も変わっていないこと。

- タスク: 名前・ノート・状態・優先度・日時・リマインダー・タグ・リスト・繰り返しの内容
- サブタスク: 作られた分がすべての深さでそのまま揃っていること（追加・削除・移動・編集・完了があれば対象外）

一度でも手を入れた次の回は利用者のタスクとして残す。取り消しの記録は
アプリの実行中だけ持つため、再起動後は次の回と完了した回はただの 2 つのタスクになる。
