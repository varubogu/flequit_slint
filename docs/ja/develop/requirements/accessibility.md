# アクセシビリティ要件

WCAG 2.1 の一般則そのものは規格を参照する。本書は **Flequit として決めたこと** のみを書く。

## 準拠目標

- **目標**: WCAG 2.1 レベル AA
- **段階**: レベル A → レベル AA
- **適用範囲**: すべての UI（`crates/flequit-ui`）

Slint はネイティブ描画であり、HTML / ARIA は存在しない。
Web 由来のガイドライン（セマンティック HTML、`aria-*` 属性、axe-core 等の検査ツール）は
本プロジェクトには適用されない。対応する仕組みは Slint の `accessible-*` プロパティと、
それが構築するアクセシビリティツリーである。

## 実装ルール

対話可能な要素には以下を **必ず** 付ける。詳細は
[`../rules/ui.md`](../rules/ui.md) の「アクセシビリティ」を参照。

- `accessible-role`
- `accessible-label`
- `accessible-action-default`（省略すると支援技術からもテストからも到達できない）
- 状態を持つ要素は `accessible-checked` / `accessible-expanded` /
  `accessible-item-selected` 等も設定する

## 数値基準

| 項目 | 基準 |
| --- | --- |
| コントラスト比（通常テキスト） | 4.5:1 以上 |
| コントラスト比（大きなテキスト） | 3:1 以上 |
| 最小タップ / クリック領域 | 48px |
| 拡大表示 | 200% まで横スクロールなしで表示 |

## 設計上の前提

- **色だけに依存して情報を伝えない**（形状・アイコン・テキストを併用する）
- **ホバー必須の操作を作らない**（タッチ環境に存在しないため）
- すべての機能をキーボードのみで操作可能にする。
  キーバインドは [`usability.md`](./usability.md) の「キーボード操作」を参照
- 支援技術の対象: スクリーンリーダー（NVDA / VoiceOver / TalkBack）

## 検証

- **自動**: `crates/flequit-ui/tests/interaction.rs` がアクセシビリティツリー経由で
  UI を駆動する。`accessible-*` が欠けている要素はこのテストから到達できず落ちるため、
  実装ルールの遵守はテストで担保される。
  設計上の制約は [`../design/testing.md`](../design/testing.md) の
  「操作の結合テスト（UI シェル）」を参照
- **手動**: キーボードのみでの操作確認、スクリーンリーダーでの読み上げ確認、
  ブレークポイント境界でのタップ領域確認
